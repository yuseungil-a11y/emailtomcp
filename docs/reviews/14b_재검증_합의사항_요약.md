# 2차 재검증 합의사항 (데카르트 13번 + Spinoza 14번 종합)

데카르트(기능검증)와 Spinoza(보안검토)가 Edison의 1차 보안수정(12번 문서)을 각자 독립적으로 재검증했고, **동일한 신규 Medium 취약점을 서로 다른 각도에서 수렴해 확인**했다. Edison이 "참고 수준의 잔존 위험"이라 적었던 항목이 실제로는 승인 절차를 우회하는 유출 경로임이 두 번 확인됨.

## N-1 / R-1 (동일 건, Medium → 수정 필요)
- 데카르트 표기: R-1. Spinoza 표기: N-1. 완전히 동일한 근본원인.
- 작성창([보내기])의 _autosave()와 send_draft_now()가 별도 writer 작업으로 분리되어 있어, 그 틈에 같은 MCP 토큰의 update_draft가 끼어들면 사용자가 보지 못한 내용(예: 외부 BCC)이 승인·send스코프·레이트리밋 전부 없이 발송됨.
- 공격자는 send_draft 응답의 decision=edit로 정확한 타이밍 신호까지 받음.

## N-2 (Spinoza만 발견, Medium)
- compose_window.py의 주소검증 오류 QMessageBox가 메일에서 온 Reply-To 주소(따옴표 local-part 보존됨, 실측 확인)를 AutoText로 그대로 표시 — 원클릭 UNC 로드 가능성.
- Edison이 "메일유래 문자열이 들어가는 QMessageBox는 없다"고 했던 판단이 틀렸음이 실측으로 확인됨.
