# 로그 에러코드 체계 구현 — Edison

## 1. 중앙레지스트리(신규) — `core/error_codes.py`
`ErrorCode(StrEnum)`, 카테고리별번호체계:
- `EMCP-1xxx`메일수신(IMAP/POP3): IMAP_CONNECT_FAILED(1001), IMAP_AUTH_FAILED(1002), IMAP_OPERATION_FAILED(1003), POP3_CONNECT_FAILED(1010), POP3_AUTH_FAILED(1011), POP3_OPERATION_FAILED(1012)
- `EMCP-2xxx`메일발송(SMTP): SMTP_CONNECT_FAILED(2001), SMTP_AUTH_FAILED(2002), SMTP_RECIPIENTS_REFUSED(2003), SMTP_RESPONSE_ERROR(2004), SMTP_COMM_FAILED(2005)
- `EMCP-3xxx`MCP서버: MCP_SERVER_START_FAILED(3001), MCP_PORT_UNAVAILABLE(3002)
- `EMCP-4xxx`저장소/DB: DB_MIGRATION_FAILED(4001), DB_SCHEMA_TOO_NEW(4002)
- `EMCP-5xxx`자동업데이트: UPDATE_SIGNATURE_INVALID(5001), UPDATE_MANIFEST_REJECTED(5002)
- `EMCP-6xxx`UI: SINGLE_INSTANCE_LISTEN_FAILED(6001)
- `EMCP-9xxx`일반: UNKNOWN(9000)

`describe(code)`함수로한국어설명조회(Enum멤버또는문자열모두입력가능, 모르는코드도예외없이안내문구반환). 기존autoreply/rules의reason_code(비즈니스분기용문자열)는전혀안건드림 — 완전히별개인진단/로그전용체계.

중복검사테스트(test_error_codes.py): .value중복금지, 코드포맷(EMCP-NNNN)검증, 모든멤버에설명있는지확인.

## 2. 예외클래스보강 — `core/errors.py`
`EmailToMcpError.__init__(*args, error_code: ErrorCode|None=None)` 키워드전용속성추가. TransientError/PermanentError/AuthError/PolicyError/SecurityError는자체__init__없어 그대로상속받아모두error_code=...로호출가능(지정안하면None, 기존호출부전혀안깨짐). `update/verifier.py`의ManifestRejected(자체__init__있음)도 기본값ErrorCode.UPDATE_MANIFEST_REJECTED항상달도록수정.

## 3. 로그출력에코드포함 — `app.py`
`_ErrorCodeFormatter(logging.Formatter)`신설, setup_logging()의포매터로교체. 동작: ①logger.error(...,extra={"error_code":...})명시값우선 ②없으면exc_info로로깅된예외객체의.error_code속성확인 ③둘다없으면코드미부착(일반로그는그대로). record변형안하고포맷팅된문자열에만덧붙이는방식 — file/console핸들러가같은포매터공유해도중복부착안됨(회귀테스트확인).

## 4. 실제적용지점
- IMAP(incoming/imap.py) connect(): LoginError→AuthError(IMAP_AUTH_FAILED), 그외→TransientError(IMAP_CONNECT_FAILED)
- POP3(incoming/pop3.py) connect(): error_proto→AuthError(POP3_AUTH_FAILED), 그외→TransientError(POP3_CONNECT_FAILED)
- SMTP(outgoing/smtp.py) _connect()/test_connection()/send_mail(): 인증실패→SMTP_AUTH_FAILED, 수신자거부→SMTP_RECIPIENTS_REFUSED, 4xx/5xx응답→SMTP_RESPONSE_ERROR, STARTTLS미지원/알수없는보안모드→SMTP_CONNECT_FAILED, test_connection일반통신실패→SMTP_CONNECT_FAILED, send_mail일반통신실패→SMTP_COMM_FAILED(연결이후발송중실패와구분)
- MCP서버(app.py McpServiceRunner.start()): 포트충돌(PortUnavailableError)→warning(MCP_PORT_UNAVAILABLE), 기타시작실패→exception(MCP_SERVER_START_FAILED)
- DB마이그레이션(storage/migrations/runner.py): 버전역행거부→PermanentError(DB_SCHEMA_TOO_NEW), 마이그레이션함수실행중예외(이전엔로깅자체없었음)→exception(DB_MIGRATION_FAILED)추가후재발생
- 자동업데이트서명검증(update/keys.py verify_minisign Ed25519검증실패2곳+update/verifier.py해시충돌SecurityError): 모두error_code=UPDATE_SIGNATURE_INVALID. 소비하는update/checker.py의SecurityError/ManifestRejected로그라인에도extra추가해실제로그에코드찍히게함.
- 단일인스턴스listen()실패(app.py SingleInstanceGuard.try_acquire()): 경고로그에extra={"error_code":SINGLE_INSTANCE_LISTEN_FAILED}추가.
