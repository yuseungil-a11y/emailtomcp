## 1. 요약: 조건부 Go

- 새 테스트 9개 파일만 지정해 실행했고 **65건 모두 통과**했습니다(17.8초).
- 자동 테스트로 확인할 수 있는 §12.3 P2 항목은 1건(잡 토큰 403, P2에 잡 토큰 자체가 없어 시험 불가)을 빼고 모두 충족을 확인했습니다.
- 다만 §12.3 필수 기준 중 3건이 측정되지 않았습니다: 실제 Claude Code 시나리오 7종, C-14 Origin 실측 기록, 커버리지(mcp_server 90%·전체 75%). §12.1은 "100% 충족 + 데카르트 Go"가 Phase 종료 조건이라 무조건 Go는 낼 수 없습니다.
- **코드 수준 Go**(다음 단계 개발 계속 가능) / **v1.1.0 출시 게이트는 보류**(조건 C1~C3 완료 후 해제)로 판정을 나눕니다.
- 범위 밖 P1 버그 2건은 판정에서 제외하고 4장에 따로 기록. ①번은 직접 재현까지 완료, 우선순위 높음.

## 4. 범위 밖 P1 버그 2건 (판정 미포함)

### BUG-① [우선순위: 높음 / 심각도: 상] 인코딩 안 된 UTF-8 헤더 메일 파싱 시 정보 소실
- **직접 재현함.** From/Subject를 RFC 2047 인코딩 없이 UTF-8 바이트 그대로 둔 메일을 `parse_eml(raw)`에 넣으면 `mail/mime/parse.py:84` `_unfold`에서 `TypeError`.
- 결과: `parse_limited=True`로 떨어지며 `from_addrs=[]`, `message_id=None`, `body_text=''`, `date=None`.
- 영향: 발신자 미표시, 회신 스레드 끊김, MCP `get_message` 본문 빈 값, P3에서 AuthGate/LoopGuard 입력 오염 우려.
- RFC 6532(SMTPUTF8) 메일·일부 국내 레거시 발송 시스템에서 실제 발생 가능.
- 권고: **v1.0.x 패치로 P3 진입 전 필수 처리**. 원인은 `email.message.Message`가 비ASCII 헤더를 `Header` 객체로 돌려주는데 문자열을 기대. 한글 fixture에 "8비트 UTF-8 헤더", "8비트 EUC-KR 헤더" 2종 추가 권고.

### BUG-② [우선순위: 낮음 / 심각도: 하] 2자 이하 LIKE 검색에서 `%`·`_` 미이스케이프
- `storage/repositories/messages.py:399~401`, `ESCAPE` 없음. `%` 또는 `_` 한 글자 검색 시 모든 메일이 일치.
- SQL 인젝션은 아님(바인딩 파라미터 사용), 결과 부정확 정도.
- 권고: 다음 정기 패치에서 `ESCAPE '\'` + 이스케이프 추가.

## 5. 종합 판단

**조건부 Go.** P2 구현(보안 계층 L1/L2/L3, 승인·TOCTOU, 감사, 레이트리밋, 프록시·핸드셰이크, UI·매뉴얼)은 자동 검증 가능한 범위에서 설계 의도를 충족. 다음 단계 개발은 계속 가능.

**v1.1.0 출시 전 해소 조건(우선순위 순)**
- **C1(필수, 출시 차단)**: 실제 Claude Code 설치 환경에서 stdio 프록시 시나리오 7종 + HTTP 직결 1·4종 수행, 버전 기록. in-process 테스트는 같은 SDK끼리라 실제 프로토콜 협상·`--mcp-stdio-proxy` 진입·실제 stdin/stdout 중계를 검증 못함. 실패 시 P2 기능 전체 무용 위험.
- **C2(필수)**: pytest-cov 설치, mcp_server 90%(분기 포함)·전체 75% 측정 및 보강(Galileo).
- **C3(필수, 문서)**: DESIGN.md §6.1·§6.3·§7.7·§0.3·§11.5에 3장 차이 7건 + 포트변경 버튼 표현 차이 반영.
- **C-14**: 합격/불합격이 아니라 "기록" 요건. 기본경로(stdio 프록시)는 영향 없음(프록시 자신의 httpx2가 Origin 미전송), HTTP 직결(고급)에만 해당. **출시 차단 사유 아님**, C1 실측 때 함께 기록. 그 전까지 매뉴얼에 "HTTP 직결에서 Origin을 보내는 클라이언트는 거부될 수 있음" 안내 권고.
- **이월(P3)**: 잡 토큰 403 테스트(2e), 승인 요청 폭주 상한(O-1, 스피노자 검토).
- **별도 트랙**: BUG-①(v1.0.x 패치, P3 진입 전 필수), BUG-②(정기 패치).
