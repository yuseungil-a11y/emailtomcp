## 4. Edison의 "남은 위험" 평가

### R-1 [Medium, 상향 권고] MCP 초안 수동발송 경합 (L-7 유형)
- 위치: compose_window.py:347-376(_on_send), compose_window.py:327-334(_autosave), app.py:734-750(send_draft_now)
- 원인: [보내기]가 _autosave()(writer 작업1)와 send_draft_now(writer 작업2)를 별도로 실행. 두 작업 사이 같은 토큰의 update_draft가 끼어들면, 사용자가 화면에서 본 내용이 아니라 DB의 변경된 내용이 user_send로 승인 없이 나감.
- update_draft에 호출빈도 제한 없어 반복호출로 경합 승률을 높일 수 있음.
- 자동저장 실패는 예외를 삼키고 경고로그만 남긴 채 발송 계속(:333-334) — 이 경우 MCP가 바꾼 내용이 그대로 나감.
- 필요 권한은 draft 스코프뿐. "Claude 초안작성→사용자 검토 후 발송"이 주 사용흐름이라 단순 참고 수준보다 심각.
- 권고: ①send_draft_now가 화면 스냅샷해시를 받아 저장+outbox전이를 writer 트랜잭션 하나로 처리 ②작성창 열기 시점에 MCP 편집권한 회수(cancel_for_edit/Decision.EDIT 활용) ③자동저장 실패 시 발송 중단.

### 기타 잔여위험 평가
- **UNC 실측 미수행**: 타당한 잔여위험(Low). 코드상 원인 제거는 강한 테스트로 단언됨. 출시 전 수동확인 항목으로 충분.
- **QMessageBox 일부 AutoText**: 타당(Low). 메일유래 값이 들어가는 곳은 main_window.py:858(저장경로)뿐이고 attachments_safety.py:73에서 `<>` 제거해 태그 생성 불가. 추가로 folder_tree_model.py:115의 계정상태 툴팁이 IMAP 서버 오류문자열을 리치텍스트로 해석할 수 있음(사용자가 직접 설정한 서버값이라 Low, 다음 정리 때 처리).
- **추가 발견 [Low] M-1 쿨다운 우회**: approval.py:309-319, 거부쿨다운이 초안단위라 새 초안으로 재요청하면 회피 가능(분당5건/동시3건 상한은 여전히 걸림, 승인피로는 남음). 권고: 토큰 단위 쿨다운 추가.
