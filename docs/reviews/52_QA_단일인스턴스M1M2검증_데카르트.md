# 단일인스턴스 M-1/M-2 수정 검증 — 데카르트

## 판정: Go
M-1·M-2모두코드상+실제두프로세스기동통합재현에서해결확인. 코드미수정.

## 1. 코드검증(local_handshake.py)
- **환경변수무관여부확인**: GetUserNameW는프로세스토큰에서사용자읽어환경변수안봄. 2단계호출(버퍼크기먼저받고재호출)+argtypes/restype지정모두올바름. 폴백os.getlogin()도Windows서같은API써서환경변수의존재발생안함.
- **한글계정명구분확인**: 문제없음(utf-8인코딩+sha256앞16자리를키에섞어 한글계정명끼리충돌안함, 파이프이름도ASCII로안전).
- **공용이름폴백확인**: 보안안약해짐(다른사용자가같은이름파이프먼저잡아도HMAC검증서막혀SecurityError, 토큰미전송 — 영향은가용성뿐).

## 2. 신규테스트3건평가
- **[Low] M-2테스트가항상통과하는구조**: test_different_env_vars_still_yield_same_key가_current_user_identity를고정값으로바꿔놓은채환경변수만바꿔 — 구현이예전처럼getpass.getuser()써도통과, M-2를결정적으로검증못함. 권고: win32에서는대체안하고 USERNAME지운경우+가짜값경우모두_current_user_identity()/_single_instance_key()결과같은지확인하도록변경.
- **M-1테스트**: token_a!=token_b확인유효. 단 "kim" not in token단언은hex문자열에k·i·m안들어가서항상참(해롭진않으나의미없는단언).
- **폴백테스트**: 유효.

## 3. 지정테스트재현과플레이키테스트
지정4파일5회연속 매번15passed. test_single_instance_guard_qt.py만-v로20회+부하조건3라운드(18회)추가 총38회모두통과(재현안됨). **[Low,잠재플레이키]** Edison쪽에선실패1회관찰됨, qtbot.wait(300)뒤activated["count"]==1확인하는고정대기방식이라느린CI서깨질수있음(이번수정과무관). 권고: qtbot.waitUntil(lambda: activated["count"]==1, timeout=3000)로교체.

## 4. 매뉴얼(01_메인창.md "중복실행방지"절)
정확함(실제단일인스턴스판정은데이터디렉터리별QLockFile이함, --data-dir다르면함께실행된다는설명이코드와맞음). 사소한누락(Info): 이렇게두번째로뜬인스턴스는listen()이실패해MCP핸드셰이크를못받음 — 매뉴얼에이점없음.

## 5. 실전재현(프로세스2개를서로다른환경변수로기동)
A프로세스는USERNAME="홍길동"으로실제QLocalServer(UserAccessOption)열음. B프로세스는두조건: (a)USERNAME/USER/LOGNAME전부제거(예전방식getpass.getuser()는"No username set"오류) (b)USERNAME="completely-other"(예전방식이라면다른값나옴). **두경우모두키가EmailToMCP-single-instance-cf80f848926bad85로A와같았고, client_handshake가HMAC검증된포트54321을돌려받음.** 예전구현이었다면키가어긋나는조건이므로 M-2는실전에서도해결된것으로판단.

## 참고(이번범위밖, Info또는Low)
- GetUserNameW는도메인없이사용자명만반환 — 로컬계정kim과도메인계정DOMAIN\kim은같은키됨(예전구현과같은수준, 더엄격히하려면SID사용).
- 해시16자리는salt없어 흔한계정명은사전대입으로되돌릴수있음(계정명노출방지는약한수준가림정도로보는게맞음).
- 비Windows서os.getlogin()(제어터미널기준)과getpass.getuser()(환경변수기준)섞여쓰임 — su같은환경서GUI와프록시키가달라질수있어 pwd.getpwuid(os.geteuid())사용권고.
- **[Spinoza확인권고] 비Windows서try_acquire가listen()전에QLocalServer.removeServer(key)호출** — 데이터디렉터리다른두번째인스턴스가첫인스턴스의소켓파일을지우고그채널을가로챌수있음(Windows파이프엔해당안됨, 기존동작).
