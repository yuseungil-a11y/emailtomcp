## 3. "간략한 답변" 반영 여부: 부분 반영

- **반영된 부분**: 프롬프트에 간결하게 쓰라는 지시가 있다. [Claude 초안 만들기] 버튼도 있다.
- **누락**
  1. 메일 요약 기능이 없다. 요약 UI, `messages.ai_summary` 같은 저장 컬럼, 요약 생성 경로가 모두 빠져 있다.
  2. [Claude 초안 만들기]의 실행 경로가 정의되지 않았다. 규칙 없이 잡을 만드는지, 이때 LoopGuard와 쿨다운을 적용하는지 정해지지 않았다.
  3. "간략한 답변"을 어떻게 해석할지 사용자 확인이 필요하다(Q8). 후보는 (a) 짧은 자동 답장, (b) 요약 제시, (c) 둘 다.
- **개선안**
  - 잡 유형에 `kind IN ('auto_reply','manual_draft','summary')`를 둔다.
  - J 스코프에 `submit_summary{summary≤500, suggested_reply?≤300}`를 추가한다.
  - 미리보기에 [요약] 버튼과 요약 패널, "짧은 답 제안 → 초안"을 넣는다.
  - 신규 메일 자동 요약 옵션을 두되 기본값은 off로 한다.
  - 수동 요청은 쿨다운과 스레드 상한 적용에서 제외한다. 결과는 항상 draft로 두고 auto_send는 금지한다.
  - 요약 응답 시간 목표는 p95 30초 이내로 한다.

### 5.3 버전과 업데이트 결정 사항
- **단일 버전 소스**: `pyproject` version 하나만 둔다. 앱은 `importlib.metadata`로 읽고, 빌드 시 Windows VERSIONINFO와 macOS Info.plist에 주입한다. CI에서 태그가 `vX.Y.Z`와 일치하는지 검사한다.
- **0.0.0의 의미**: 개발 시작 버전으로 보고 릴리스하지 않는 방안이 있다. 첫 배포를 0.0.1로 할지 0.1.0으로 할지는 사용자 확인이 필요하다(Q9).
- **비교 규칙**: `packaging.version`으로 비교한다. pre-release 채널을 둘지 정한다. 다운그레이드는 금지한다.
- **배포 채널**: GitHub Releases API를 쓴다. 저장소 공개/비공개에 따라 토큰 필요 여부가 갈린다. 비인증 요청 한도가 시간당 60회임을 고려한다.
- **무결성**: SHA-256과 서명(minisign 또는 sigstore 등)을 둘 다 검증한다. HTTPS만으로는 부족하다.
- **설치 방식**
  - Windows: 헬퍼 프로그램이나 설치본으로 교체한다.
  - macOS: .app 번들을 교체하고 quarantine/notarization을 처리한다. 원자적으로 교체하고 실패하면 롤백한다.
- **업데이트 전 처리**: 실행 중인 잡을 정리하고, 발송 중인 메일을 마무리하고, MCP 서버를 종료한다. DB를 백업한 뒤 마이그레이션한다.
