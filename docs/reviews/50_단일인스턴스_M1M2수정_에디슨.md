# 단일 인스턴스 M-1/M-2 수정 — Edison

## 수정내용
`mcp_server/local_handshake.py`: getpass.getuser()(환경변수USERNAME등의존) 대신 **OS API로사용자식별값획득**. Windows: ctypes.WinDLL("advapi32")로GetUserNameW직접호출(job_dir.py의기존패턴재사용, pywin32추가없음), 실패시os.getlogin()폴백. 비Windows: os.getlogin()먼저시도후getpass.getuser()폴백. 얻은식별값은 `hashlib.sha256(identity.encode("utf-8",errors="surrogatepass")).hexdigest()[:16]`로해시해키에섞음(기존_로 치환하던로직제거-한글계정명전부빈문자열충돌하던M-1원인). 식별값전혀못얻는극단경우만공용이름폴백(fail-safe, 보안약화아님).

**M-2해결원리**: OS API는환경변수를안읽어(Windows GetUserNameW는토큰기반) GUI프로세스와--mcp-stdio-proxy프로세스가서로다른(축소된)환경변수가져도같은계정이면항상같은해시키계산.
