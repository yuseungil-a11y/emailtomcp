## H-1 의존성 해시고정
uv로 잠금파일4개(`packaging/release/locks/`: requirements-release/build-backend/manifest/audit.txt, --universal --python-version 3.12 --generate-hashes). release.yml pip설치는 `--require-hashes --no-deps -r <lock>`(의존성) + `--no-deps --no-build-isolation -e .`(앱자체) 두방식뿐. `--upgrade pip`제거, build job에 pip check추가. editables 누락 발견→잠금에추가해해결. 로컬실측: release잠금전체(PySide6포함) 해시설치+pip check+import 성공. vpk: nupkg sha256을 VPK_SHA256으로고정(nuget.org카탈로그packageHash와대조), 받은nupkg를 sha256sum -c대조후 로컬피드에서만설치(실제설치성공). vpk --version없어 `dotnet tool list -g`+`vpk -h`첫줄로버전확인. pip-audit: audit job이 잠금4개를 --require-hashes --disable-pip로검사(build는이job통과후시작), build job은 설치된환경을 --path --skip-editable로검사(별도venv). 로컬결과 전부"No known vulnerabilities".

## H-2 서명직전독립검증
`--expect-version`필수(신규·재서명둘다), 후보latest.version/후보URL속태그/사람입력값 3개모두일치해야진행(check_expected_version). URL접두사만검사하는스키마의틈(버전1.0.1인데URL은v1.0.0가리키는후보가스키마는통과)을잡는테스트추가. 후보+모든산출물에 `gh attestation verify`필수(--repo, --signer-workflow, --source-ref refs/tags/v<ver>, --deny-self-hosted-runners), 실패시중단, gh경로는--gh로지정. 확인화면에released_at/notes_summary전문/산출물별URL추가. provenance는build job(산출물)으로이동, 후보매니페스트·SHA256SUMS의provenance는읽기전용job(prepare-release)에서생성.
