# 발송 승인 창

Claude가 MCP로 초안 **발송을 요청**하면(발송 모드 "확인", 기본값) 이 창이 뜹니다.
**사용자가 [승인]해야만 실제로 발송됩니다.** Claude 쪽에는 승인 기능이 없습니다.

## 언제, 어떻게 뜨나요

- 다른 작업을 방해하지 않도록 **포커스를 빼앗지 않고** 뜹니다. 동시에 운영체제
  알림("Claude 발송 승인 요청")과 작업표시줄 깜빡임으로 알려 줍니다. 알림을 클릭하거나
  창을 클릭해서 확인하세요.
- 창을 놓쳤다면 메인 창 폴더 트리의 **작업 > 승인 대기**를 클릭한 뒤, 목록에서
  메일을 더블클릭(또는 [승인 창 열기])하면 다시 열 수 있습니다.

## 화면 구성

- **보내는 계정**, **받는사람 / 참조 / 숨은참조** 전체, **제목**, **본문**, **첨부** 목록이
  모두 표시됩니다.
- 내 계정과 **다른 도메인**의 수신자 옆에는 주황색 **외부** 배지가 붙습니다. 외부로
  나가는 메일인지 꼭 확인하세요.
- 아래쪽에 남은 시간(120초)이 표시됩니다.
- 제목·주소·계정 이름은 **글자 그대로** 표시됩니다. 제목에 `<img ...>` 같은 태그가
  들어 있어도 그림이나 서식으로 바뀌지 않고 문자 그대로 보이므로, 이상한 문자열이
  보이면 거부하세요.
- 한 연결(토큰)이 동시에 띄울 수 있는 승인 요청은 **3건까지**이고, 거부한 초안은
  **60초 동안** 다시 요청할 수 없습니다(승인 창이 연달아 뜨는 것을 막기 위함).

## 버튼

| 버튼 | 동작 |
|---|---|
| **거부**(기본 버튼) | 발송하지 않습니다. 초안은 "작성 중" 상태로 돌아가고 Claude에는 "거부됨"으로 알려집니다. |
| **수정 후 발송** | 승인 요청을 취소하고 작성 창을 엽니다. 내용을 고친 뒤 작성 창의 [보내기]로 직접 보냅니다. 이때 초안은 **사용자 소유로 넘어와**, 그 초안을 만든 Claude도 더는 수정·삭제·발송 요청할 수 없습니다(Claude에는 "이 초안은 사용자가 처리합니다"로 알려집니다). |
| **승인** | 화면에 보이는 내용 그대로 보낼편지함에 넣어 발송합니다. |

- 실수 방지를 위해 창이 뜬 뒤 **1.5초 동안은 버튼과 키 입력이 막혀 있습니다.** 그 뒤에
  버튼이 켜집니다. 기본 버튼은 [거부]라서, 다른 창에서 치던 `Enter`가 들어와도
  승인되지 않습니다.
- 창을 그냥 닫거나 `Esc`를 누르면 아무것도 결정하지 않은 채 닫힙니다(메일은 승인 대기
  함에 그대로 남습니다).

## 시간 제한

- **120초** 안에 결정하지 않으면 Claude에는 "승인 대기 중"이라고 알리고, 메일은
  **승인 대기** 함에 남습니다. 창이 열려 있다면 그 뒤에도 승인/거부할 수 있습니다.
- **24시간** 동안 아무 결정도 하지 않으면 승인 요청이 만료되어 초안("작성 중")으로
  돌아갑니다.

## 승인이 무효가 되는 경우

승인은 **승인 요청 시점의 내용**(수신자·제목·본문·첨부)에 묶여 있습니다.

- 승인 대기 중인 초안은 Claude도, 작성 창도 **수정할 수 없습니다.**
- 그래도 승인 시점에 내용이 요청 때와 다르면(예: 창을 띄워 둔 사이 다른 경로로 바뀜)
  승인은 **무효 처리**되고 초안으로 돌아갑니다. 이때는 내용을 다시 확인한 뒤 새로
  요청하거나 직접 보내세요.

## 발송 한도

Claude를 통한 발송은 승인 여부와 관계없이 **시간당 20건, 하루 100건**까지입니다.
한도를 넘으면 [승인]을 눌러도 "발송 상한을 넘었습니다" 안내가 뜨고 메일은 승인
대기 함에 남습니다. 시간이 지난 뒤 다시 승인하세요.
