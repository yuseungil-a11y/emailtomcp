# 작성 창

새 메일 작성, 회신/전체회신, 전달(인라인/첨부)이 모두 같은 작성 창을 씁니다.

## 여는 방법

| 동작 | 여는 방법 | 비고 |
|---|---|---|
| 새 메일 | 툴바/메뉴의 "새 메일"(`Ctrl+N`) | 먼저 폴더 트리에서 보낼 계정(또는 그 계정의 폴더)을 선택해 두어야 합니다 |
| 회신 | "회신"(`Ctrl+R`) | 그리드에서 메일을 선택한 상태에서 사용 |
| 전체회신 | "전체회신"(`Ctrl+Shift+R`) | 내 주소와 별칭은 수신자에서 자동으로 빠집니다 |
| 전달 | "전달"(`Ctrl+L`) | 먼저 "인라인 전달" / "첨부로 전달" 중 하나를 고르는 작은 창이 뜹니다 |
| Claude 초안 수정 | [발송 승인 창](06_발송승인.md)의 **[수정 후 발송]** | Claude(MCP)가 만든 초안을 그대로 엽니다. 위쪽에 출처 안내가 표시됩니다 |

창을 여는 순간 **초안이 즉시 만들어집니다**(아직 아무것도 입력하지 않아도).
그 뒤로는 30초마다 자동으로 저장되고, 창을 닫을 때도 한 번 더 저장됩니다.
[취소]를 누르면 이 초안은 지워집니다(단, 이미 발송 이력이 생긴 초안은 지우지
않고 그대로 둡니다). **[수정 후 발송]으로 연 Claude 초안은 [취소]해도 지워지지 않고**
지금까지 고친 내용으로 저장만 됩니다.

## 입력란

- **받는사람 / 참조 / 숨은참조**: 쉼표(`,`)로 여러 주소를 구분해 입력합니다.
  입력 중 최근 주고받은 주소가 자동완성으로 제안됩니다.
- **제목 / 본문**: 평문(일반 텍스트)만 지원합니다. HTML 서식 작성은 아직
  지원하지 않습니다.
- **보내기**를 누르기 전에 주소 형식을 간단히 검사합니다 — `이름@도메인` 형식이
  아닌 주소가 있으면 보내기 전에 알려줍니다.

## 첨부파일

- **[파일 추가]** 버튼으로 선택하거나, 파일을 창에 바로 **드래그앤드롭**해도
  됩니다.
- 첨부 총 용량이 **25MB**를 넘으면 경고가 뜹니다(그래도 보낼 수는 있습니다 —
  실제로 발송 서버가 거부할 수 있으니 참고만 하세요).
- 목록에서 항목을 선택하고 **[선택 제거]**로 뺄 수 있습니다.
- **회신(전체회신 포함) 초안에는 원본 메일의 첨부파일이 기본으로 포함됩니다.**
  보내기 전에 필요 없는 첨부를 선택해서 제거할 수 있습니다.

## 전달 방식

- **인라인 전달**: 원본 메일의 내용을 본문 안에 그대로 넣습니다(원본 첨부도
  함께 포함됩니다).
- **첨부로 전달**: 원본 메일 전체를 `.eml` 파일 하나로 첨부합니다.

## 보내기

[보내기]를 누르면 즉시 발송 대기열(Outbox)로 넘어가고, 몇 초 안에 실제
발송이 시도됩니다. **사용자가 작성 창에서 직접 보내는 메일은 별도 승인 절차 없이
바로 발송됩니다.** 승인 절차는 Claude가 MCP로 발송을 요청할 때만 적용됩니다
([06_발송승인.md](06_발송승인.md)). 승인 대기 중인 초안은 작성 창에서 보낼 수
없습니다 — 승인 창에서 [수정 후 발송]을 누르면 작성 창으로 넘어옵니다.

- **나가는 내용은 항상 [보내기]를 누른 순간 작성 창에 보이던 내용입니다.** 저장과
  발송 대기열 등록이 한 번에 처리되므로, 그 사이에 다른 곳(예: Claude)에서 초안을
  바꿔도 화면에 없던 수신자나 본문이 섞여 나가지 않습니다.
- 저장에 실패하면 발송하지 않고 오류 창으로 알려 줍니다. 작성 창은 열린 채로 남으니
  내용을 확인한 뒤 다시 [보내기]를 누르세요.
- 오류 창의 문구(예: 형식이 잘못된 주소)는 서식 없는 글자 그대로 표시됩니다.

- 발송이 일시적인 오류(네트워크 등)로 실패하면 자동으로 재시도 대기열에
  들어갑니다 — 왼쪽 트리의 "보낼편지함"에서 진행 상태를 볼 수 있습니다.
- 영구적인 오류(잘못된 수신자, 인증 실패 등)이면 즉시 "실패"로 표시됩니다.
