# 계정 설정

**도구 > 계정**에서 엽니다. 계정 목록 창에서 **[추가]**로 새 계정을 등록하거나,
목록에서 더블클릭(또는 **[편집]**)으로 기존 계정을 수정합니다.

## 프리셋

창 위쪽의 **프리셋 표**에서 메일 서비스를 고르면 호스트/포트/보안 방식이
자동으로 채워집니다.

| 프리셋 | 수신 | 송신 | 안내 |
|---|---|---|---|
| Gmail | IMAP 993(SSL) | 465(SSL) | 2단계 인증 + 앱 비밀번호(16자) 필수 |
| 네이버 | IMAP 993(SSL) | 465(SSL) | 2단계 인증 + 앱 비밀번호 필수. 메일 환경설정에서 IMAP/POP3 사용을 켜야 함 |
| 다음 | IMAP 993(SSL) | 465(SSL) | 2단계 인증 + 앱 비밀번호 필수 |
| 카카오 | IMAP 993(SSL) | 465(SSL) | 2단계 인증 + 앱 비밀번호 필수. IMAP/POP3 "사용" 켜기 |
| 하이웍스 | **POP3 전용** 995(SSL) | 465(SSL) | IMAP 미지원 — 프로토콜이 POP3로 고정됩니다. 서버 폴더·읽음 동기화가 되지 않습니다(로컬 전용) |
| Microsoft 365 / Outlook.com | — | — | **이 버전에서는 선택할 수 없습니다**(OAuth2 필요, P4 예정) |
| 사용자 지정 | 직접 입력 | 직접 입력 | — |

## 탭

- **일반**: 표시 이름, 이메일 주소, 보내는 사람 이름, 서명, 수신 주기(분).
  - 이메일 주소는 계정을 만든 뒤에는 바꿀 수 없습니다(식별자 역할).
- **수신**: 프로토콜(IMAP/POP3, 하이웍스는 고정), 호스트/포트/보안, 사용자명,
  비밀번호. **[연결 테스트]**로 실제 로그인까지 확인할 수 있습니다(최대 15초,
  그동안 창이 멈추지 않습니다).
  - 기존 계정을 편집할 때 비밀번호 칸을 비워두면 기존 비밀번호가 그대로
    유지됩니다.
- **송신**: 호스트/포트/보안, 사용자명(수신과 다를 때만 입력). **[연결 테스트]**
  버튼도 있습니다.
- **자동회신**
  - **이 계정에 자동회신 규칙 적용**: 체크해야 이 계정으로 받은 메일에
    [규칙](04_규칙설정.md)이 적용됩니다(기본은 꺼짐). 전역 자동회신 스위치
    ([설정 > 자동회신](07_설정.md))가 꺼져 있으면 "전역 자동회신이 꺼져 있어 지금은
    적용되지 않습니다" 안내가 보이며, 체크박스는 그대로 바꿀 수 있습니다.
  - **내 별칭**: 쉼표로 구분한 내 다른 주소입니다. 전체회신 때 수신자에서 빠지고,
    자동회신이 내 메일에 답장하지 않도록 하는 데에도 쓰입니다.
  - **신뢰 Authentication-Results ID**, **수신 경계 서버(Received by)**: 즉시발송의 인증
    전제조건입니다. 메일 서비스별로 어떤 값을 믿을 수 있는지 실측이 끝난 서버에서만 입력할 수
    있어야 해서, **이번 버전에서는 입력란이 비활성**이며 "다음 업데이트에서 실측 완료 후
    제공됩니다" 안내만 보입니다(예전에 입력해 둔 값이 있으면 표시만 되고 바뀌지 않습니다).
    이번 버전의 자동회신은 모두 초안이라 동작에는 영향이 없습니다.

## 비밀번호 저장 위치

비밀번호는 데이터베이스가 아니라 **운영체제 키체인(keyring)**에만 저장됩니다.
평문으로 어디에도 남지 않습니다.
