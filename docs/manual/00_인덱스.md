## 처음 실행했을 때

1. **메일 > 받기**(또는 `F5`)를 누르기 전에, 먼저 **도구 > 계정**에서 계정을 하나
   이상 추가하세요. 계정이 없으면 폴더 트리가 비어 있고 메일을 주고받을 수 없습니다.
2. 계정을 추가하면 왼쪽 폴더 트리에 해당 계정과 폴더(받은편지함/보낸편지함/
   임시보관함/휴지통)가 나타납니다.
3. 받은편지함을 클릭하면 가운데 메일 그리드에 목록이 뜨고, 메일 한 통을 선택하면
   오른쪽/아래 미리보기 패널에 내용이 표시됩니다.

## Claude와 연결하기(P2부터)

Claude Code(또는 Claude Desktop)에서 이 앱의 메일을 읽고 초안을 만들게 하려면
**Claude > Claude/MCP 패널**에서 토큰을 발급하고 등록 명령을 한 번 실행하세요.
자세한 순서는 [05_Claude_MCP패널.md](05_Claude_MCP패널.md)에 있습니다. Claude가
발송을 요청하면 [발송 승인 창](06_발송승인.md)이 뜨고, **사용자가 승인해야만**
발송됩니다.

이렇게 대화하며 메일을 검색·작성·발송·회신하는 기능은 **Claude Desktop만으로
충분**합니다(Claude Code 전용 기능이 아닙니다). 다만 [자동회신](04_규칙설정.md)
(메일이 오면 앱이 백그라운드에서 스스로 답장 초안을 만드는 기능)만은 예외로,
이 기능을 쓸 때만 claude CLI 설치가 필요합니다 — 자세한 내용은
[04_규칙설정.md](04_규칙설정.md)의 "이 기능을 쓰려면(claude CLI 필요)"를 보세요.

## 지금 버전(P3 1차)에서 아직 동작하지 않는 기능

아래 기능은 화면에 버튼/메뉴는 있지만, 이번 버전에서는 안내만 표시되고 실제
동작은 다음 단계에서 구현됩니다.

| 기능 | 표시 방법 | 구현 예정 |
|---|---|---|
| Claude 초안 만들기 / 요약(미리보기에서 직접 누르는 기능) | 미리보기 패널의 버튼(비활성 + 툴팁) | P3 다음 업데이트 |
| 자동회신 즉시발송(사람 확인 없이 바로 보내기) | 규칙 편집의 동작 목록에 비활성으로 표시 — 지금은 자동회신 결과가 모두 초안 | P3 다음 업데이트 |
| claude CLI 버전·인증 방식 표시, [테스트] | Claude/MCP 패널 서버 탭 안내(경로 고정은 잡 탭에서 동작) | P3 다음 업데이트 |
| 프록시 설정 | 설정 창에 입력란은 있으나 저장만 됨 | U2 |
| 앱 안에서 업데이트 자동 다운로드·설치 | 업데이트 확인·알림·다운로드 페이지 링크까지만 동작(설치는 직접) | U2 |
| 긴급정지 버튼 | 툴바(비활성 + 툴팁) | P3 다음 업데이트 |

이 목록과 각 화면 문서는 기능이 추가될 때마다 함께 갱신됩니다
(프로젝트 `CLAUDE.md`의 "UI 기능 변경 시 사용 설명서 동기화" 규칙).
